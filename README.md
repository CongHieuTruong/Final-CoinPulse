# CoinPulse

CoinPulse (or CryptoScope) is a basic web application built with Python and Flask. In the current MVP version, the application provides a simple interface that allows users to input cryptocurrency-related keywords (e.g., Bitcoin) and displays the result back on the screen.

## Key Features
- **Basic User Interface**: A simple input form using HTML.
- **Basic Data Processing (Echo Test)**: Receives input data from the user via the POST method and displays it directly on the interface.

## Requirements
- Python 3.x
- Flask

## Installation and Usage

1. **Clone the repository (if you haven't already):**
   ```bash
   git clone https://github.com/CongHieuTruong/CoinPulse.git
   cd CoinPulse
   ```

2. **Install dependencies:**
   Run the following command to install required packages:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   Execute the `app.py` file:
   ```bash
   python app.py
   ```

4. **Usage:**
   Open your web browser and go to: `http://127.0.0.1:5000/`. You can try entering a keyword (e.g., Bitcoin) and click the Submit button to see the response from the system.
